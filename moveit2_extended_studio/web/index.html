Served by Rerun, in its own tab rather than embedded here. Start it with ros2 run moveit2_extended_studio rerun_bridge and open http://<robot>:9090.

It logs the arm, the dresspack shape, and — the reason for using Rerun rather than another viewport here — bend utilisation, twist and cable strain as time series on the same timeline as the 3D scene. Dragging the timeline shows the pose at the moment the carrier got tight, which is the question this stack exists to answer.

Not embedded in an iframe on purpose: the viewer wants the whole window, and two scroll/zoom surfaces fighting each other is worse than a second tab. RViz remains the other option and needs no pip install — crx5ia_objectives/config/objectives.rviz has the same panel controls as this page.
